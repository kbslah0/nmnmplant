# كوكب نمنم

> عالم صغير، سويتُه من حبي إلج... وكلشي بيه إسمج.

هدية رقمية على شكل كوكب متحرك. تلمس الكوكب (أو زر الدخول) وتفتح قصة مكتوبة من القلب، مع أغنية **«خليك معايا» — عمرو دياب** تبدأ بهدوء وتذوب بالثيم.

الموقع **مصمم للهاتف أولاً**، ويشتغل كذلك على التابلت واللابتوب. كل شي محلي: الخطوط، المكتبة، والأغنية — بلا خوادم خارجية وبلا تتبع.

---

## تشغيل الموقع على جهازك

افتح الملف:

```
start-website.bat
```

هذا يشغّل سيرفر محلي صغير ويفتح المتصفح على:

```
http://127.0.0.1:8080/
```

> **لا تفتح `index.html` بالضغط المزدوج** إذا قدرت. بعض المتصفحات تمنع تحميل الخطوط المحلية أو الصوت من `file://`. استخدم `start-website.bat` أو أي سيرفر محلي.

بديل يدوي (لو ما اشتغل البات):

```bash
# داخل مجلد المشروع
python -m http.server 8080
```

ثم افتح `http://localhost:8080/`.

على ماك أو لينكس:

```bash
python3 -m http.server 8080
```

لتجربة الموقع على جوالك بنفس شبكة الواي فاي:

```bash
python -m http.server 8080
```

ثم من الجوال افتح:

```
http://IP-الكمبيوتر:8080
```

(تلاقي IP الكمبيوتر من `ipconfig` على ويندوز، ومن إعدادات الشبكة على ماك).

## كيف تنشرها كهدية (رابط للجوال)

الموقع ثابت بالكامل، ما يحتاج بناء أو `npm`. يكفي ترفع محتويات المجلد كما هي:

1. **Netlify Drop** — اسحب مجلد `nimnim-planet` كامل إلى https://app.netlify.com/drop، وخذ الرابط.
2. **Vercel** — ارفع المجلد كمشروع Static.
3. **GitHub Pages** — ارفع الملفات إلى مستودع وفعّل Pages.
4. أو أي استضافة تدعم ملفات ثابتة.

بعد النشر:

- أرسل الرابط لها واتساب/إنستغرام.
- إذا تحب صورة المشاركة تظهر صح، بدّل في `index.html`:
  ```html
  <meta property="og:image" content="https://YOUR-DOMAIN.com/og-image.jpg">
  ```
  خليها رابط كامل بدل `og-image.jpg` النسبي.
- تأكد أن الاستضافة تسمح بتحميل ملف MP3 بحجم ~3.7MB. Netlify/Vercel/GitHub Pages كلها تسمح.

## الأغنية والصوت

- الملف: `audio/khalik-maaya.mp3`
- الأغنية: «خليك معايا» — عمرو دياب.
- الملف معالج مسبقاً حتى يبدأ **هادئاً**:
  - فيد إن (Fade in) على أول 4.5 ثانية.
  - مستوى أقل من الأصل بـ 7 ديسيبل.
  - فيد أوت على آخر 4 ثواني، لتكون إعادة التشغيل أنعم.
- **المتصفحات تمنع التشغيل التلقائي بالصوت.** لذلك:
  - إذا سمح المتصفح، تبدأ الأغنية لحالها بعد ثواني من فتح الصفحة.
  - إذا منع، أول لمسة على **الكوكب** أو زر **«ادخلي عالم نمنم»** أو زر **«خليك معايا»** تشغّلها.
  - زر «خليك معايا» في أعلى الصفحة يشغّل/يوقّف الأغنية في أي وقت.
  - صوت الجهاز نفسه يتحكم بمستوى السماع النهائي.

> الأغنية مستخدمة هنا كهدية شخصية. إذا رح تنشر الرابط بشكل عام، تأكد من حقوق الاستخدام حسب بلدك/المنصة.

## تخصيص سريع

### النصوص
كل النصوص العربية في `index.html`:

- عنوان الكوكب والجملة التعريفية.
- الرسالة، الحكايات، الوعود، الرسائل العشوائية (في `main.js` للأخيرة).
- الخاتمة والتوقيع.

كلمات البحث المفيدة:

```
كوكب نمنم
وصلتي،
أعرف إنّج تعبانة
وعودي
ومستحيل أتركج
```

### الاسم
الاسم الحالي **نمنم**. إذا بغيت تبدله:
- ابحث عن `نمنم` في `index.html`، `main.js`، و`README.md`.
- في `index.html`: العنوان `<title>`، وسم `apple-mobile-web-app-title`، والهيدر، والرسالة.
- في `main.js`: مصفوفة `notes` (رسائل القلب العشوائية).
- في `styles.css`: لا يوجد اسم، فقط تنسيقات.

### الألوان
كل الألوان في أول `styles.css` داخل `:root`:

```css
--bg: #160f2b;
--plum: #302044;
--violet: #573b75;
--wine: #63365e;
--pink: #ffd6e9;
--lav: #d9c5ff;
--gold: #ffe6a6;
--text: #fff8ff;
```

### الأغنية
- استبدل `audio/khalik-maaya.mp3` بملفك (يفضل MP3).
- إذا غيّرت الاسم، بدّل المسار في `<audio id="song" ...>` داخل `index.html`.
- بدّل اسم الأغنية الظاهر في زر الصوت وفي فوتر القصة (ابحث عن «خليك معايا»).
- إذا بغيت تبدأ الأغنية من نقطة معينة، عدّل `audio.currentTime` في `main.js` بعد `audio.play()` — أو اتركها من البداية.

### صورة المشاركة
`og-image.jpg` موجودة بمقاس 1200×630. تستطيع استبدالها بصورة ثانية بنفس المقاس.

## تفاصيل تقنية

- **Three.js** لبناء الكوكب والقلوب والدبدوب والنجوم.
- **WebGL** مع بديل CSS (كوكب وردي بقلب) إذا كان الجهاز لا يدعم WebGL.
- **خطوط محلية**: Aref Ruqaa للعناوين، Tajawal للنصوص.
- **صوت**: عنصر `<audio>` بسيط، بلا مكتبات إضافية.
- **أداء**: تقليل عدد الجزيئات وDPR على الهاتف، إيقاف مشهد 3D أثناء قراءة القصة، وتعطيل الفلاتر الثقيلة على الهاتف.
- **حركة أقل**: يحترم `prefers-reduced-motion`.
- **وصول**: زر واضح للدخول، دعم لوحة المفاتيح، إغلاق بـ Esc، وتحديث `aria` لزر الصوت والرسائل.
- **بلا تتبع**، بلا تحليلات، بلا طلبات خارجية.

## ملاحظات للجوال

- الأفضل بالطول (Portrait). في الوضع الأفقي يوجد تخطيط مختصر مخصص.
- الصفحة تتعامل مع `safe-area` لهواتف iPhone.
- إذا كنت تفتح الرابط داخل واتساب/إنستغرام، قد تحتاج لمسة أولى لتشغيل الصوت.
- إذا كانت الأغنية ما تظهر: تأكد أنك تستخدم سيرفر محلي أو رابطاً مستضافاً، وليس `file://`.

## اختبار سريع قبل الإرسال

1. افتح الموقع من الجوال (أو وضع الجوال في المتصفح).
2. المس الكوكب — لازم تفتح القصة.
3. تأكد أن الأغنية تبدأ بهدوء عند الدخول، وزر الصوت يوقفها ويشغّلها.
4. نزّل للأسفل حتى الخاتمة، وتأكد أن زر «رجوع للكوكب» يرجعك.
5. جرّب زر «رسالة ثانية» في قسم «خذي رسالة من قلبي».
